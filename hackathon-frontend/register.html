GitHub Repository Registration Rules

  • Each team must register with a unique team name, and duplicate team names will not be accepted.
  • All participants must enter valid GitHub usernames, and a GitHub account can be registered under only one team.
  • After successful registration, a GitHub repository will be automatically created, and all team members must accept the collaborator invitation to access it.
  • Teams must check their email after registration to receive the GitHub repository link and further instructions.
  • All project development must be done only in the assigned repository, and the repository name must not be changed.
  • The repository README.md must include the project title, problem statement, solution description, technology stack, setup instructions, and team members.
  • Teams should commit and push code regularly, avoid uploading unnecessary large files, and ensure the project is original without plagiarism.
  • The final submission deadline is April 2, 2026 at 10:00 AM, and commits after this time may not be considered for evaluation.
